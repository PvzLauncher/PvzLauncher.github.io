# 下载

> 在此页面，你可以了解 PvzLauncher 的系统兼容性、运行依赖以及官方提供的下载渠道。

## 快速下载

如果你使用的是 **Windows 10 或更高版本的 64 位操作系统**，可以直接下载 PvzLauncher。

* [下载 PvzLauncher (稳定版)](/files/pvzlauncher.stable.latest.zip)
* [下载 . NET 10 Desktop Runtime (Windows x64)](https://builds.dotnet.microsoft.com/dotnet/WindowsDesktop/10.0.13/windowsdesktop-runtime-10.0.13-win-x64.exe)（如果尚未安装）

## 兼容性

|平台|支持情况|备注|
|-|-|-|
| Windows 10+ x64 |✅ 完全支持|原生支持的平台，也是唯一提供官方支持的平台。|
| Windows 10- x64 |❌ 不支持| 不提供兼容性保障。|
| Windows x86 |❌ 不支持|不提供 32 位版本。|
| Linux x64 |⚠️ 理论上可运行|可尝试通过 Wine 运行，但不保证兼容性，也不提供相关技术支持。|
| Android / macOS / FreeBSD / Web |❌ 不支持|不在支持范围内，暂无支持计划。|

## 运行依赖

PvzLauncher 依赖 **. NET 10 Desktop Runtime**。运行程序前，请确保已安装对应的运行时环境。

* [. NET 10 官方下载页面](https://get.dot.net/10)

> [!IMPORTANT]
> 请根据你的操作系统和处理器架构选择正确的运行时版本。对于 Windows x64 用户，可直接使用上方提供的 Windows Desktop Runtime 安装包。

## 下载

PvzLauncher 提供两种更新通道，以满足不同用户的使用需求。

| 更新通道 | 说明 |
| --- | --- |
| **Stable (稳定版)** | 以稳定性为优先，更新频率相对较低，适合日常使用。 |
| **Development (开发版)** | 可以更早体验最新的开发成果，但可能存在尚未修复的问题或其他不稳定因素。 |

**Stable（稳定版）**

* [官方网站下载](/files/pvzlauncher.stable.latest.zip)

* [官方网站下载](/files/pvzlauncher.dev.latest.zip)
